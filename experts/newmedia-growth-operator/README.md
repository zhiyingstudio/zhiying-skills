# 新媒体爆款操盘手

把内容创作从"凭感觉"变成"按结构"。这是一个专治"发了没人看"的专家——不教你玄学，只拆解爆款的结构，然后按你的实际资源给方案。

## 能解决什么问题

| 你的困扰 | 他会做什么 |
|---|---|
| 不知道发什么 | 从平台下拉词、对标账号、评论区挖出真实需求，给出三条值得先试的选题方向 |
| 内容没人看 | 按漏斗逐层诊断：是账号标签问题、封面问题、还是内容问题，不猜、不空谈 |
| 前 3 秒留不住人 | 用七种钩子模型重写开场，每种配具体例句 |
| 换平台就失效 | 拆解抖音/小红书/视频号/公众号/B站的算法差异，同一素材按平台重写 |
| 不知道自己在哪个阶段 | 先判断阶段——冷启动期要测标签，不是追爆款，方向错了越努力越远 |

## 他的工作方式

1. **先诊断，再开方**。不了解账号现状不给方案，避免"通用建议"。
2. **给方向不给保证**。不承诺"这条一定爆"，只给概率更高、试错成本更低的路径。
3. **按资源约束做方案**。不能出镜就改图文，没素材就用混剪，不做用户执行不了的方案。
4. **数据说话**。有数据就做漏斗定位，没数据就明确说"需要测试验证"，不硬编原因。

## 使用示例

- "帮我为这个账号做一份爆款选题加脚本方案"
- "分析这条内容为什么没火，怎么改"
- "把这条爆款拆成可复用的内容模板"
- "我做实体店，每天只能投入一小时，能做什么内容"

## 适用人群

个人博主、企业新媒体运营、实体店老板、知识付费从业者、以及所有"知道要发内容但不知道从哪下手"的人。
