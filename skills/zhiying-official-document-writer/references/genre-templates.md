# 各文种完整模板

> 使用说明：`{花括号}` 为占位符，需替换为实际内容。**不得编造政策文号、数据、领导表述。**

---

## 一、通知

```
关于 {事由} 的通知

{主送机关}：

为 {目的或依据}，经 {会议/研究} 决定，现将有关事项通知如下：

一、{事项一标题}
{具体内容，含执行标准与要求}

二、{事项二标题}
{具体内容}

三、工作要求
（一）{责任单位} 负责 {具体任务}，于 {时间节点} 前完成。
（二）{责任单位} 负责 {具体任务}。

特此通知。

{发文单位}
{成文日期}
```

---

## 二、通报

```
关于 {表彰/批评/情况} 的通报

{主送机关}：

{背景说明：何时何事}。

为 {目的}，经研究，决定 {对 XX 予以通报/将有关情况通报如下}：

一、基本情况
{事实陈述，客观中立}

二、主要原因
{分析，批评类要指出问题根源，表彰类要提炼经验}

三、工作要求
{针对性的要求，明确落点}

特此通报。

{发文单位}
{成文日期}
```

**注意**：批评类通报要把握分寸，事实清楚、定性准确，避免情绪化表达。

---

## 三、请示（一文一事）

```
关于 {请示事项} 的请示

{上级机关}：

{背景与必要性，简明扼要，2-3 句}

{具体请示事项，明确到可批准的程度}。

{可行性与预期效果说明}。

妥否，请批示。

{发文单位}
{成文日期}
```

**红线**：

- 一文一事，不得一文多请
- 不得越级请示（特殊情况需说明并抄送被越过的机关）
- 不得抄送下级机关
- 请示事项必须明确，避免"请予支持"这类模糊请求

---

## 四、报告

```
关于 {事项} 的报告

{上级机关}：

根据 {依据}，现将 {事项} 有关情况报告如下：

一、基本情况
{时间、范围、总体情况}

二、主要做法
（一）{做法一}。{具体措施 + 数据结果}
（二）{做法二}。{具体措施 + 数据结果}

三、存在问题
{具体问题，实事求是}

四、下一步工作打算
（一）{打算一}
（二）{打算二}

特此报告。

{发文单位}
{成文日期}
```

**注意**：报告中**不得夹带请示事项**。需要上级批复的，另行文请示。

---

## 五、批复

```
关于 {请示事项} 的批复

{请示单位}：

你单位《关于 {请示文件标题} 的请示》（{文号}）收悉。经研究，现批复如下：

一、{明确同意/不同意/原则同意}
二、{补充要求或注意事项}

此复。

{发文单位}
{成文日期}
```

---

## 六、函

```
关于 {事项} 的函

{受文单位}：

{说明发函缘由，简要陈述背景}。

为 {目的}，现将有关事项函告如下：

一、{事项}
二、{事项}

请予支持为盼。／特此函达。／特此函商，请予回复。

{发文单位}
{成文日期}
```

**注意**：函用于不相隶属机关之间。对上级用请示，对下级用通知，对平级或不相隶属用函。

---

## 七、会议纪要

```
{会议名称}纪要

{第 X 期}

时间：{YYYY} 年 {MM} 月 {DD} 日 {HH}:{MM}
地点：{地点}
主持人：{姓名、职务}
出席人员：{姓名、职务}
列席人员：{姓名、职务}
记录人：{姓名}

一、会议听取了
{听取了什么报告或汇报}

二、会议认为
{对形势、问题的判断与共识}

三、会议决定
（一）{决定事项一：明确做什么、谁负责、什么时限}
（二）{决定事项二}

四、会议要求
{对落实工作的要求}

{发文单位}
{成文日期}
```

**要点**：

- 用第三人称「会议」，不出现"我认为""大家觉得"
- 只记议定事项，不记讨论过程与个人发言倾向
- 决定事项必须有责任主体与时限

## 八、工作总结

```
{单位} {YYYY} 年工作总结

一、主要工作与成效

（一）{重点工作一}
{做法 + 数据结果}

（二）{重点工作二}
{做法 + 数据结果}

二、存在的问题与不足
{具体问题一，说明表现与影响}
{具体问题二}

三、下一步工作打算
（一）{打算一，明确目标与举措}
（二）{打算二}

{单位名称}
{成文日期}
```

**反面示例（禁止）**：

> 一、高度重视，加强领导
> 二、狠抓落实，务求实效
> 三、存在问题：学习不够深入，工作还有差距

—— 这是典型的无信息量总结。要求：**每条成效带数据，每条问题说具体表现。**

## 九、讲话稿 / 发言稿

```
在 {会议/活动名称} 上的讲话

{讲话人} {职务}
（{YYYY} 年 {MM} 月 {DD} 日）

同志们：

{开头：交代背景与会议意义，2-3 句}

下面，我讲 {X} 点意见。

一、{观点一}
{论述 + 具体事例或数据}

二、{观点二}
{论述}

三、{观点三}
{论述}

同志们，{号召性结尾}。

谢谢大家。
```

**要点**：

- 口语化程度高于其他公文，但不用网络语言
- 观点要鲜明，一段一个意思
- 可与 PPT 配合：讲话稿按段落可对应 PPT 页面

---

## 十、述职报告

```
{姓名} {时间段} 述职报告

一、履职情况
（一）{分管/负责的工作}
{做法 + 结果数据}
（二）{重点工作}
{做法 + 结果数据}

二、存在不足
{具体短板，不用万能话}

三、下一步打算
{可落地的计划}

述职人：{姓名}
{成文日期}
```

## 层级序号规范

```
一、
（一）
1.
（1）
```

依次使用，不得跳级，不得混用。
