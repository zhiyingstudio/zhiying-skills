# 公文语言规范与常见错误对照

公文语言的核心是**准确、简明、庄重、得体**。四者顺序不可颠倒——先准确，再求简，再求庄，最后才谈得体。

---

## 一、词语规范

### 1.1 高频规范词及正确用法

| 词 | 含义 | 正确用例 | 错误用例 |
|---|---|---|---|
| 兹 | 现在 | 兹定于3月5日召开…… | 兹有关于……的事情 |
| 悉 | 知道、收到 | 收悉、已悉 | 悉知全部情况（应为"知悉"） |
| 拟 | 打算、准备 | 拟提请审议 | 拟似、拟将予以 |
| 经 | 经过 | 经研究决定 | 经过研究后决定（"经过……后"冗余） |
| 兹将 | 现将 | 兹将有关事项通知如下 | 兹将以下事项通知于下 |
| 特此 | 特别在此 | 特此通知、特此函告 | 特此通知如下（"特此"本身即结束，不再接内容） |
| 妥否 | 是否妥当 | 妥否，请批示 | 妥否，请批准（"妥否"配"批示"） |
| 当否 | 是否恰当 | 当否，请批示 | — |
| 请予 | 请给予 | 请予批准、请予支持 | 请给予批准（"给予"口语） |
| 望 | 希望（上级对下级） | 望遵照执行 | 望予以批准（方向错了） |
| 希 | 希望（平行或上级） | 希即遵照办理 | — |
| 敬 | 恭敬（平行或上行） | 敬请指导 | 敬请遵照执行（方向错了） |
| 报请 | 上报并请求 | 报请市政府批准 | 报请批准我们（缺主语对象） |
| 核 | 审核 | 核发、核销、核准 | 核实一下（口语） |

### 1.2 文种专用结束语（不可混用）

| 文种 | 结束语 |
|---|---|
| 通知 | 特此通知。 |
| 通报 | 特此通报。 |
| 报告 | 特此报告。（或"以上报告，请审阅。"） |
| 请示 | 妥否，请批示。（或"以上请示，请批复。"） |
| 批复 | 此复。 |
| 函（商洽） | 请予函复。（或"盼复。"） |
| 函（告知） | 特此函告。 |
| 意见 | 以上意见，请予考虑。 |
| 纪要 | （不写结束语，末尾以"会议决定了以下事项"收） |
| 决定 | （不写结束语） |

**常见错误**：把"特此通知"用在报告里；把"请批示"用在平行机关函件里（平行机关无隶属关系，用"请予函复"或"盼复"）。

## 二、常见错误对照

### 2.1 语体错误：把公文写成散文

| 错误 | 修正 |
|---|---|
| 在这春意盎然的美好时节，我们齐聚一堂…… | 为进一步推进××工作，现召开××会议。 |
| 大家一定要高度重视、深刻认识…… | 各部门要充分认识××工作的重要性。 |
| 可以说，这是我们工作的一个重要里程碑。 | （删除，公文中不作评价性抒情） |

**判据**：删掉形容词后句子仍然完整 → 该形容词多余。

### 2.2 冗赘

| 错误 | 修正 |
|---|---|
| 关于××工作有关事项的通知 | 关于××工作的通知 |
| 经过认真研究后决定 | 经研究决定 |
| 在××方面做了大量卓有成效的工作 | 扎实开展××工作 |
| 基本上可以说是 | （删除，公文不用模糊限定叠加） |
| 为了更好地进一步推进 | 为推进 |
| 请各单位于3月5日之前将材料报送上来 | 请各单位于3月5日前报送材料 |
| 截至目前为止 | 截至（"截止到目前"亦错） |
| 大约有100人左右 | 约100人（"大约"与"左右"重复） |
| 涉及到 | 涉及 |
| 通过……的方式来进行…… | 通过……进行……（或直接用动词） |

### 2.3 逻辑与搭配错误

| 错误 | 问题 | 修正 |
|---|---|---|
| 请遵照执行 | 用于上行文 | 平行文用"请予支持"，下行文才用"遵照执行" |
| 特此请示，请批准 | "特此请示"不规范 | 妥否，请批示 |
| 以上报告，请批示 | 报告不能要求批示 | 以上报告，请审阅 |
| 请批复 | 用于平行函件 | 请予函复 |
| 关于申请××经费的请示报告 | 文种混用 | 关于申请××经费的请示 |
| 各县、区人民政府，各有关单位： | 顺序错乱 | 各区、县人民政府（按规范排序） |

### 2.4 序号与层级

规范层级序号（不可跳级、不可混用）：

```
一、          （第一层：汉字 + 、）
（一）        （第二层：括号汉字，后不加顿号）
1.           （第三层：阿拉伯数字 + 下脚点）
（1）         （第四层：括号阿拉伯数字，后不加标点）
```

**常见错误**：
- `一.` `一，` —— 第一层必须用 `、`
- `（一）、` —— 括号序号后不加顿号
- `1、` `1，` —— 第三层用 `1.` 下脚点
- 一级用 `一、`，二级直接跳到 `1.` —— 必须 `（一）` 过渡

### 2.5 称谓与时态

| 错误 | 修正 | 说明 |
|---|---|---|
| 你单位 | 贵单位（平行）/ 你单位（下行） | 视行文方向 |
| 我们单位 | 我单位、我公司 | 公文中不自称"我们" |
| 贵单位应该…… | 请贵单位…… | 平行机关不用"应该" |
| 我司 | 我公司（正式公文）/ 我司（商务函件可） | 视文种 |
| 上述、前述 | 一致即可 | 同一文中不可混用 |
| 现已、目前、当前 | 择一使用 | 同一段落不混用 |

## 三、格式规范要点

### 3.1 标题

**标准式**：发文机关 + 关于 + 事由 + 的 + 文种

```
××市人民政府关于进一步加强城市管理工作的通知
```

- 事由中除介词"关于""对"外，一般不用其他介词
- 标题中除法规、规章名称加书名号外，一般不用标点
- 转发性通知：`××市人民政府转发省人民政府关于××工作的通知的通知`（避免"的通知的通知"，可简化为"××市人民政府转发省人民政府关于××工作的通知"）

### 3.2 主送机关

- 顶格写，末尾加冒号
- 多个主送机关用顿号或逗号分隔，按层级排序
- 上行文只写一个主送机关（请示不得多头主送）

### 3.3 正文

三段式结构（最稳）：

1. **开头**：发文的依据、目的、背景 —— "为……，根据……，现就……通知如下"
2. **主体**：事项本身，分条列项
3. **结尾**：执行要求或专用结束语

### 3.4 落款

- 发文机关署名 + 成文日期
- 成文日期用阿拉伯数字全称：`2026年3月5日`（不写"二〇二六年三月五日"的混用格式，除特殊要求）

## 四、自检清单

交付前逐条核对：

- [ ] 文种选对了吗？（上行/下行/平行）
- [ ] 标题是"发文机关 + 关于 + 事由 + 的 + 文种"吗？
- [ ] 主送机关排序对吗？请示是否只有一个主送？
- [ ] 结束语与文种匹配吗？（报告≠请批示）
- [ ] 层级序号是否按 `一、→（一）→ 1. →（1）` 规范？
- [ ] 有没有散文式抒情、形容词堆砌？
- [ ] 有没有"截止到目前""大约……左右""涉及到"这类冗赘？
- [ ] 称谓前后一致吗？（我单位/我公司、贵单位/你单位）
- [ ] 数字用法一致吗？（统计数字用阿拉伯数字，成文日期用阿拉伯数字）
- [ ] 删掉任意一个句子，意思会变吗？不会 → 删。
